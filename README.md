# mangen

Утилита командной строки для генерации манифеста файлов каталога с вычислением криптографических хэш-сумм.

**Автор:** Агибалов Владислав Сергеевич

**Репозиторий:**  
https://github.com/multmine1/safeboard_2026_11_C_mangen_

## Назначение

`mangen` рекурсивно обходит каталог и формирует список файлов с хэш-суммами их содержимого.

Формат вывода:

```text
<relative_path> : <HASH>
```

Манифест записывается в стандартный поток вывода (`stdout`).

Ошибки обработки файлов и каталогов выводятся в стандартный поток ошибок (`stderr`).

## Использование

```bash
./mangen [DIR_PATH] [OPTIONS]
```

Если `DIR_PATH` не указан, обрабатывается текущий каталог.

### Параметры

| Опция | Назначение |
|---|---|
| `-h`, `--help` | Справка |
| `-v`, `--version` | Версия, автор и Git commit hash |
| `-e PATTERN` | Исключение файлов и каталогов по wildcard-шаблону |
| `--sha256` | SHA-256 (по умолчанию) |
| `--sha384` | SHA-384 |
| `--sha512` | SHA-512 |
| `-j N`, `--threads N` | Количество рабочих потоков |
| `--queue-size N` | Начальная ёмкость очереди каталогов |

## Архитектура

Проект разделён на семь собственных статических библиотек.

| Библиотека | Назначение |
|---|---|
| `matcher` | Wildcard-шаблоны, НКА, ДКА, минимизация |
| `queue` | Многопоточная очередь с динамическим расширением |
| `catalog` | Хранение, сортировка и синхронизация записей файлов |
| `hash` | Потоковое вычисление SHA-256/384/512 |
| `hash_pool` | Параллельное распределение и выполнение заданий хэширования |
| `walker` | Многопоточный рекурсивный обход каталогов |
| `manifest` | Форматирование и упорядоченный вывод манифеста |

Основное приложение находится в `app/`.

## Сборка

После реализации CMake-конфигурации проект будет собираться следующими командами:

```bash
cmake -S . -B build \
    -DCMAKE_BUILD_TYPE=Release \
    -DBUILD_TESTING=ON

cmake --build build --parallel
```

## Тестирование

```bash
ctest --test-dir build --output-on-failure
```

## Установка

```bash
cmake --install build --prefix "$PWD/build/install"
```

Исполняемый файл будет установлен в:

```text
build/install/bin/mangen
```

## Особенности

- Многопоточный рекурсивный обход каталогов.
- Динамическое увеличение ёмкости конкурентной очереди.
- Собственный wildcard-автомат с минимизацией ДКА.
- Поддержка SHA-256, SHA-384 и SHA-512.
- Детерминированный порядок строк манифеста.
- Разделение стандартных потоков вывода и ошибок.
- Автоматизированные тесты с GoogleTest и CTest.
- Возможность сборки без доступа к интернету.
- Контроль целостности исходного ZIP-архива по SHA-256.
